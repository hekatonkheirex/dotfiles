# Hyprland Quickshell bar

This is the Quickshell bar for the current Hyprland session.

The shell uses a restrained Material 3 design system while preserving the
Tokyo Night or Matugen palette selected in Settings. `Theme.qml` owns the
semantic color roles, shape scale, spacing, typography, and motion tokens;
the bar, popups, launcher, notifications, settings, OSD, and lock surface
consume those roles instead of defining their own visual language.

The bar is a top capsule with:

- Hyprland workspaces, filtered per monitor, including configured persistent workspaces before their first visit and an occupancy cue for workspaces with open windows
- a desktop-entry launcher with search
- PipeWire speakers and microphone controls with Material 3 sliders and mute switches
- `brightnessctl` screen brightness controls with a Material 3 slider
- UPower battery state with an anchored details popup for health, charge cycles, energy, power rate, and time remaining
- a clock with a month calendar popup
- a Wayland idle inhibitor for caffeine mode
- a confirmed power menu for lock, logout, suspend, reboot, and power off
- native system-tray icons with activation and menu support (middle-click opens menus)
- native DBus notifications with a bar history popup and primary-screen toasts
- a settings window with persistent local appearance preferences
- a native PAM lockscreen available through Quickshell IPC
- native Wayland idle actions with caffeine inhibition

For manual testing, run it directly with:

```sh
quickshell --no-duplicate --path "$HOME/.config/quickshell"
```

The shell exposes `bar.toggleLauncher` through Quickshell IPC, so a Hyprland keybind can open the launcher with:

```sh
quickshell ipc --path "$HOME/.config/quickshell" call bar toggleLauncher
```

The media-key and screenshot bindings use the same Quickshell IPC surface for volume, mute, brightness, and `grim`/`slurp` screenshots. Volume and brightness changes show a short Quickshell OSD. `Print` selects a region, while `Ctrl+Print` captures the full screen. Both screenshots are saved under `~/Pictures/Screenshots` and copied as `image/png` to the Wayland clipboard when `wl-copy` is available.

The notification history can be toggled through the same IPC surface:

```sh
quickshell ipc --path "$HOME/.config/quickshell" call bar toggleNotifications
```

Clear the in-memory notification history through IPC with:

```sh
quickshell ipc --path "$HOME/.config/quickshell" call bar clearNotifications
```

The native lockscreen can be started manually for testing with:

```sh
quickshell ipc --path "$HOME/.config/quickshell" call session lock
```

It uses Quickshell's Wayland session-lock protocol and the `login` PAM service. The power-menu Lock action and `Super+Alt+L` now use this Quickshell path. Hypridle owns idle timing and invokes this Quickshell lockscreen.

The settings window is available from the gear icon at the right side of the bar, or through IPC:

```sh
quickshell ipc --path "$HOME/.config/quickshell" call bar toggleSettings
```

The `XF86Tools` and `XF86Favorites` keys both open this Quickshell settings surface; a separate compact control-center panel is not currently implemented.

Appearance, wallpaper, and notification preferences are stored in `~/.config/quickshell/settings.json`. The settings navigation includes appearance, wallpaper, notifications, and integration placeholders. Appearance supports a Wallpaper palette generated by Matugen and a stable Static Tokyo Night palette; Auto mode selects the light or dark role from wallpaper brightness. The Wallpaper page owns its image directory and uses `awww`/`awww-daemon` for rendering. The initial directory is `$HOME/Pictures/Walls`; the directory and transition type are editable from Settings, and the scanned images can be selected there. Per-monitor targeting remains a placeholder, so the current image actions apply to all outputs. The Notifications page controls enable/disable, Do Not Disturb, toast duration, and in-memory history.

When the Wallpaper palette is selected, `scripts/sync-material3-expressive.sh` regenerates the Material 3 Expressive GTK, icon, Kvantum, and SDDM variants from the live Matugen cache, then selects the matching light or dark variant for the session. Static mode selects generated Tokyo Night GTK, icon, Kvantum, and SDDM variants from the same bundle. Switching the palette updates SDDM through `pkexec` when a polkit authorization agent is available and its helper socket is healthy; otherwise it opens Kitty with a visible `sudo` prompt. SDDM themes are generated in `~/.local/share/sddm/themes`, and the result is reported with a desktop notification.

The Hyprland autostart starts `quickshell.service` through the systemd user manager; the
service owns the Quickshell process and restarts it on failure. The graphical-session target
is not activated by this Hyprland setup, so the session hook starts the service after importing
the Wayland environment.

`hypridle` owns idle actions with the existing timings: lock after 10 minutes, turn off Wayland outputs after 11 minutes, and suspend after 15 minutes. It uses Quickshell IPC for the lock screen, `wlopm` for output power, and `systemctl suspend`. The bar's Wayland Caffeine inhibitor pauses the idle daemon. If a display is manually left off, restore it with:

```sh
~/.config/quickshell/scripts/display-power.sh on
```

Quickshell and `hypridle` are the only active shell and idle owners. The `awww-daemon` user service owns wallpaper rendering, while Quickshell selects images and restores the last saved wallpaper at startup.
