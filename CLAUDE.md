# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Is

A yadm-managed dotfiles repo for an Arch Linux desktop running Niri (Wayland compositor) with a custom Quickshell-based desktop shell. The entire home directory is the repo root — yadm tracks only the dotfiles, not user data.

## Key Commands

```bash
# Bootstrap (installs packages + copies system configs)
yadm bootstrap              # or: ./install.sh

# Refresh package lists from current system
~/.local/bin/pkglist-refresh.sh

# Wallpaper + full theme pipeline
wall                        # random wallpaper → matugen → regenerate all themes → sync mode

# Theme regeneration only (no wallpaper change)
~/.local/bin/generate-all-themes.sh

# Theme mode switching
~/.local/bin/sync-theme-mode.sh dark|light|auto

# Matugen color extraction only
~/.local/bin/matugen-and-cache.sh /path/to/image.jpg
```

## Architecture

### Theming Pipeline

Wallpaper-driven Material 3 Expressive theming flows through these stages:

1. **`wall`** (`~/.local/bin/wall`) — sets wallpaper via `awww`, then triggers the pipeline
2. **`matugen-and-cache.sh`** — runs `matugen --type scheme-expressive --prefer saturation`, caches palette JSON to `~/.cache/matugen/current_palette.json`, and generates `Colors.qml` via matugen templates (`~/.config/matugen/templates/Colors.qml` → `~/.config/quickshell/config/Colors.qml`)
3. **`generate-all-themes.sh`** — runs four Python generators in `~/Projects/material3-expressive-{icons,sddm,kvantum,theme}/generate.py`. Icons/SDDM/Kvantum run in parallel; GTK theme runs sequentially after (needs sassc)
4. **`sync-theme-mode.sh`** — applies light/dark/auto across gsettings, GTK 3/4 settings.ini, Kvantum, qt6ct, and Niri focus-ring colors. Auto mode uses `auto-detect-theme.sh` (ImageMagick wallpaper brightness analysis)

All generators read from a shared palette module: `~/Projects/material3-expressive-shared/palette.py` which wraps `~/.cache/matugen/current_palette.json`.

### Quickshell (Desktop Shell)

Entry point: `~/.config/quickshell/shell.qml` — a QML-based shell providing status bar, popups (audio, wifi, bluetooth, brightness, battery, calendar, notifications, launcher, quick menu), OSD overlays, lock screen, and a Command Center.

Key patterns:
- **IPC via file triggers**: scripts in `~/.config/quickshell/scripts/` (launcher, lock, quickmenu) touch files in `/tmp/qs*-trigger` — `FileTrigger` QML components watch these to toggle UI
- **OSD triggers**: `/tmp/qsosd-{vol,bright,mic,airplane,bluetooth}` for on-screen display
- **Colors**: `~/.config/quickshell/config/Colors.qml` is auto-generated by matugen; `Config.qml` holds layout settings
- **Bar layout**: switchable horizontal/vertical, persisted in `~/.config/quickshell/layout` (plain text: "horizontal" or "vertical")
- **Helper scripts**: `desktop-parser.py` (app launcher data with icon resolution + caching), `voice-search.py` (offline Vosk speech-to-text), `mpris_monitor.py`/`mpris_control.py` (media integration)

### Niri Configuration

Split into modular KDL files at `~/.config/niri/`:
- `config.kdl` — main entry, includes all others
- `keybinds.kdl`, `inputs.kdl`, `outputs.kdl`, `decorations.kdl`, `windowrules.kdl`, `startup.kdl`, `environments.kdl`
- `colors.kdl` — auto-generated by `sync-theme-mode.sh` (focus ring colors from matugen palette)

### Thinkpad / System Configs

`~/.config/thinkpad/` contains system-level configs deployed by the bootstrap script via `sudo cp` with `.bak` backups: TLP (battery thresholds), udev rules (auto-brightness), PAM (fingerprint auth), zram, throttled, GRUB, journald, logind, makepkg, and timeshift-autosnap.

## Shell Environment

Zsh with zinit plugin manager, Starship prompt, zoxide (`z` for directory jumping), fzf (fuzzy finder), and eza (ls replacement). Editor is neovim (`n` alias). Package manager is paru (`update` alias).

## Git Configuration

Commits are signed with SSH key (`~/.ssh/id_ed25519.pub`). Yadm is the git wrapper — use `yadm` instead of `git` for dotfile operations.
